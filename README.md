# RFID-Management
<h2>This is a basic RFID attendance system kinda and is supposed to be the v1 of it, I'm gonna work more on it on future, so be tuned for any updates.</h2>
<br>

<h2>This projecyt was made using the folloeing stuff:</h2>
1. Arduino Nano
<br>
2. Jumper wires
<br>
3. RFID reader
<br>
4. RFID cards
<br>
<br>

<h2>The following coomands are ready to use in this version:</h2>
1. ```getData``` <br>
   This command gives the overall stats of the device.

2. ```getAttendance``` <br>
   This command gives the total attendance for the day

3. ```<student name>``` <br>
   This is used to get the stats of a specific student by writing his/her name.
